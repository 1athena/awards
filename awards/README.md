# Confirmed awards

All confirmed, publicly announced awards use the shared [Award register](#award-register)
below. Follow the applicable [legacy confirmation and delivery process](../docs/award-process.md#step-3-recipient-confirmation-and-award-delivery)
or [MathDB confirmation and payment rules](../docs/award-process-mathdb.md#5-announcement-and-payment)
before publishing an award. Preserve historical decisions; no historical reward
is automatically recalculated.

Record each contribution type in a separate row: **Mathematical solution**,
**Lean formalization** or **Exposition**. These correspond to Solution, Lean and
Exposition in the MathDB process. Preserve each recipient's attribution and the
completed public-review dates, including the precision of the original record.

For new records, link each recipient to their claim issue. Keep the applicable
rules version, fixed proof or material references, announcement, candidate
history and team-confirmed delivery status in that linked record. Legacy rows
retain their existing evidence links and history.

Update the candidate register and the corresponding index role when an award is
published. See the [record guide](../docs/records.md) for status conventions and
regeneration of the pilot index and page.
